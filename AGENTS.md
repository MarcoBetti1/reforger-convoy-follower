# Reforger workspace instructions

This repository is the local test harness and research record. The first addon, `addons/ConvoyFollower`, is under development with prepared Arland and Everon test scenes. Start with [docs/harness-handoff.md](docs/harness-handoff.md), then read [docs/operations-playbook.md](docs/operations-playbook.md) before controlling the game or Workbench. Update the playbook when a UI step is verified or fails. Keep Workshop descriptions separate from observed gameplay; [docs/raven-field-notes.md](docs/raven-field-notes.md) records the completed Raven probe.

## Fast paths verified on this machine

- Start with `npm run cli -- doctor --mod <WorkshopID>` to check installs and caches.
- Fetch a Workshop mod with `npm run mod:fetch -- --mod <WorkshopID=Name> --execute`; it uses a hidden, loopback-only dedicated server and a reusable cache under `.cache/workshop-fetch/profile/addons`.
- Host a private Conflict Arland test with `npm run conflict:host -- --mod <WorkshopID=Name> --execute`; this builds the scenario config, reuses that server cache, and verifies loopback-only UDP endpoints. Its manual in-game Direct Connect path still needs a successful live join test.
- Use `npm run client:run -- --profile .cache/client/profiles/<test> --world worlds/GameMaster/GM_Arland.ent --addon <WorkshopID> --addons-dir .cache/workshop-fetch/profile/addons --expect-game --execute` for a clean local Game Master test. `--expect-game` checks the log for a GAME transition; inspect the UI to verify actual actions.
- Add `--keep-open` to `client:run` when leaving a test window for a player; it omits the automatic timer and runs until exit or Ctrl+C. It cannot be combined with `--duration-seconds`.
- Use `npm run workbench -- validate` or `pack` with the real `.gproj`; both dry-run unless `--execute` is supplied. The helper supplies the base-game addon directory and checks the resulting pack.
- Use `npm run workbench:open -- --editor script|world|resource --execute` to open a project directly in an editor; it dry-runs by default. The Script Editor path and World Editor `-load` on GM Arland were live-tested.
- For the Convoy Follower test, use `npm run workbench:open -- --editor world --project addons/ConvoyFollower/addon.gproj --world Worlds/Tests/ConvoyFollower_Arland.ent --authorize-local-test-scripts --execute`. The opt-in flag adds Workbench's supported `-scriptAuthorizeAll` switch for this local testing process. Pass `--project` because the helper's default is an older sample. The Arland scene has three driver groups, four M923A1 trucks, and a US spawn. The owner can order a truck to **Pull off and regroup** from its M923 rear menu after a stopped arrival, and the intended return trigger is the owner's lead truck crossing the parked line homeward. The latest route and recovery changes still need live verification. Earlier three-truck following and leader voice were visually confirmed. See [docs/convoy-mapmaker-quickstart.md](docs/convoy-mapmaker-quickstart.md), [addons/ConvoyFollower/README.md](addons/ConvoyFollower/README.md), and [docs/convoy-workshop-release.md](docs/convoy-workshop-release.md).
- The Everon night demo world is `Worlds/Tests/ConvoyFollower_Everon_Night.ent`, and its scenario header is `Missions/ConvoyFollower_Everon_Night.conf`. See [docs/convoy-everon-demo.md](docs/convoy-everon-demo.md) for the Regina to Levie route, LAV seat-spawn attempt with on-foot fallback, supplies, and the night-start caveat: the scenario header sets 22:00, while bare F5 World Editor preview may inherit daytime. The revised Regina sports-ground staging and Levie roadside storage were visually inspected in World Editor; driving, seat transfer, and night start still need gameplay checks. The Soviet driver group is `Prefabs/Groups/Group_CF_Driver_USSR.et`, and the rear release action is also on standard Ural4320 cargo trucks. The combined addon passed five-configuration validation and packaging in `.cache/workbench-runs/convoy-everon-soviet-seat-final-pack-v2`; a live Soviet road/menu test remains. [docs/convoy-voice-expansion.md](docs/convoy-voice-expansion.md) contains a recording script for the next voice pass; no new audio has been recorded or wired.
- For a Soviet smoke test, open `Worlds/Tests/ConvoyFollower_Arland_USSR.ent`: an USSR spawn, three Soviet one-member driver groups with Ural4320 transport trucks, and a UAZ player vehicle on the familiar Arland test apron. It passed a unique headless probe pack, but the faction-specific interactions, rear action, and driving still require a player test.

## UI and test discipline

- Current release acceptance scope: establish autonomous repeatable one-, two-, and three-truck driving runs, inspect real gameplay and logs, and capture a demonstration video before calling the mod ready. The September 25 user request supersedes the earlier plan for user-led first-person testing. The target is a reliable Workbench and CLI loop with no user intervention.
- The game client must start with its executable directory as its working directory; `client:run` handles this. Do not use the normal client profile with its large enabled-mod set as a clean baseline.
- Windows desktop capture targets one selected window. Keep Reforger windowed at a stable size; select or activate the current returned game window before clicking. Observe, perform one action, and recapture. Do not reuse coordinates or a window handle after a transition.
- In-game Workshop search needed individual key events followed by Enter. The magnifier click did not apply the query in the observed run. A real Workshop download registered Raven for Host Mods; copying only its package did not. Reuse the registered isolated client profile for later hosting tests. Workbench's launcher Add Project dropdown and its replacement window after opening a project need fresh window selection.
- A running Reforger window may be behind Steam or Codex while still capturable; activate the target window before assuming it is minimized. The interactive **Press Enter** menu gate has not reliably accepted automated input. On the next launch, test activation, one safe click inside the game view, fresh capture, then one Return. Direct `--world` startup bypasses the gate for Game Master.
- A private player-hosted Conflict Arland run with Raven as the only enabled mod reached `GAME` and Raven logistics bootstrap at `127.0.0.1:2001`. No supply transfer was verified. For future player handoffs, use `--keep-open` when the user needs an untimed client or server session and state any explicit timer if one is set.
- Local dedicated-server client joins have timed out during authentication even with no mods and with both loopback and `local` advertised-address controls. A server download or GAME log state does not prove a player joined or a supply run completed.
- Record setup commands, scenario/world, mod IDs, exact player inputs, before/after UI, relevant log lines, outcome, and any recovery step. Stop uncertain UI input instead of repeating blind clicks.
- Use `npm run logs:summary -- --log <console.log>` for a read-only event summary, then corroborate claimed supply runs with vehicle observation and before/after resource counts. A log alone does not verify delivery.
